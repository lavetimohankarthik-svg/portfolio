## 📌 Project Overview

Welcome to my personal portfolio website!

This project is a professional platform designed to showcase my technical skills, academic background, projects, and resume. It provides recruiters, developers, and potential collaborators with an overview of my development journey and the work I have accomplished.

Built using **HTML, CSS, and JavaScript**, the portfolio focuses on presenting information through a structured and accessible interface.

The project is deployed on Vercel and serves as my digital presence for exploring career opportunities and connecting with the developer community.

The portfolio includes the following sections:

### 👨‍💻 About Me
Provides an introduction to my background, interests, and aspirations as a software developer.

Showcases my technical skills, programming knowledge, and development technologies.

### 💼 Projects

### 🎓 Education

## ⚙️ Installation & Setup

Follow these steps to clone and run the project locally.

### Prerequisites

Make sure the following tools are installed:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)
- A modern web browser such as Chrome, Firefox, or Edge
- Live Server extension for Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/lavetimohankarthik-svg/portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Open the Project in VS Code

```bash
code .
```

### 4. Run the Frontend

1. Open the `frontend` directory in Visual Studio Code.
2. Locate the main HTML file, usually `index.html`.
3. Install the Live Server extension if it is not already installed.
4. Right-click the HTML file.
5. Select **Open with Live Server**.

The portfolio will open in your browser using a local development URL.

> This setup is for the static HTML, CSS, and JavaScript frontend. If the backend is required for a particular feature, configure and start it separately using its own dependencies and instructions.
